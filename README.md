# Caderneta de Campo

App de listas de espécies avistadas, com nomes livres, contador − / +, coordenadas GPS, trilha e exportação para Excel.
Em teste para melhoria e agilidade das coletas de dados brutos em campo.

Para instalar no Android: abra o endereço do site no Chrome e toque em **Instalar app** (ou menu ⋮ → Adicionar à tela inicial).
